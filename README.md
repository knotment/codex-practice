# 会社決算タスク管理ツール

会社決算のタスクを整理するためのシンプルなシングルページツールです。
ブラウザで `index.html` を開くだけで使用できます。

## 主な機能

- 質問に答えるだけで決算タスクを自動生成
- タスク追加（担当者・期限・優先度・ステータス・補足メモ）
- カテゴリ／ステータスのフィルタ
- 進捗率、期限超過、要レビュー件数のサマリー表示
- ローカルストレージへの保存

## 使い方

1. `index.html` をブラウザで開きます。
2. 「初期設定」に決算月や消費税区分を入力してタスクを自動生成します。
3. 追加したいものがあれば「タスクを追加」から登録します。
4. 「タスク一覧」で進捗を確認し、完了・削除を行います。
